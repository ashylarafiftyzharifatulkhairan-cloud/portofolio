Cara memasang foto

Buat folder bernama foto di dalam folder yang sama dengan index.html, lalu simpan gambar dengan nama persis seperti ini:

Posisi	Nama file
Foto profil (bagian atas halaman)	foto/profil.jpg
Gambar tiga kartu proyek	foto/proyek-1.jpg, foto/proyek-2.jpg, foto/proyek-3.jpg
Galeri (tiga bingkai)	foto/galeri-1.jpg, foto/galeri-2.jpg, foto/galeri-3.jpg

Selama file foto belum ada, yang tampil hanya kotak pengganti bertuliskan “Foto kamu di sini” atau “Foto 1”. Begitu file dimasukkan, foto otomatis menutupi kotak itu tanpa perlu mengubah kode. Foto profil paling bagus berbentuk potret (tegak), sedangkan foto galeri berbentuk lanskap.

Jika fotomu berformat lain, misalnya .png, ganti ekstensinya di style.css. Cari foto/profil.jpg, foto/proyek-1.jpg, dan foto/galeri-1.jpg lalu sesuaikan.
